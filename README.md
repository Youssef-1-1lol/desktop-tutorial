# CCT360 Lab 1: Parallax

**Student:** Youssef Alhabbal  
**Course:** CCT360H5 - Web Development and Design II  
**Project:** Lab 1 - Scroll to Tell

## Project description

Signal Through the Noise is a single-page scrolling story about moving from digital overload toward focused attention. It uses layered layouts, CSS transitions, transforms, scroll-based parallax movement, and progressive content reveals.

## Files

- `index.html` - page structure and written content
- `styles.css` - layout, colours, responsive design, transitions, and animations
- `script.js` - scroll progress, parallax movement, chapter updates, and reveal effects
